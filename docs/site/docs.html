Live site and local preview

Use the public deployment or preview the same pages locally.

PowerShell 
Set-Location "D:\projekt\XLLogic"
py -m http.server 4173 -d docs/site

The public deployment lives at https://xllogic.bls-isp.net. For local preview, open http://localhost:4173 in the browser after starting the local server. For a quick smoke test, opening docs/site/index.html directly also works.

Why this split exists

Branding front, not duplicate documentation.

  • The website explains the project in a digestible form for new visitors.
  • The markdown documents remain the deeper, repository-native source.
  • That keeps architecture knowledge from being duplicated manually in two places.
