Block reference

Network Cable

Network cable defines the local discovery graph for computers, screens, and named endpoints. It is not a Python device itself, but it decides which devices a computer can see.

Network topology No direct Python device Complete
Back to block overview
In game

Discovery and diagnostics.

  • Right click prints a compact segment summary with cable count, computer count, endpoint count, XLAPI boundary count, unloaded frontier count, and endpoint type summary.
  • Shift-right-click prints the full segment detail: computer positions, boundary hints, and every discovered endpoint summary.
  • The cable connects to other network cables and to XL Logic device blocks.
  • If multiple computers share the same local segment, the debug output warns about the conflict.
Python note

This block shapes visibility, not device commands.

  • You do not call get_device() on a network cable.
  • Its effect shows up indirectly through network.names(), find_device(...), and the devices available to the computer block.
  • Screens are assigned and endpoints become reachable only if the cable topology allows it.
