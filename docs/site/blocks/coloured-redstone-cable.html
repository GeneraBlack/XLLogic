Block reference

Coloured Redstone Cable

The coloured redstone cable family filters the bus network down to exactly one channel. In the current codebase this is a family of 16 fixed-channel cable variants, one per bus channel.

Bus filter 16 fixed variants Complete
Back to block overview
In game

What each coloured cable does.

  • Each block variant is permanently tied to one channel from 0 to 15.
  • Right click prints the filtered channel and a summary of the reachable flow on that channel.
  • Shift-right-click expands the same channel view with route hops and blockers.
  • Neighbouring coloured cables only connect when their filtered channel matches.
Python note

No direct device API.

  • Like the main bus cable, the coloured filter cable is not a Python endpoint.
  • Its effect is visible indirectly through bus topology and through Redstone I/O channel methods.
