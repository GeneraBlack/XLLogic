Block reference

Light Sensor

The light sensor is the simplest environmental input block in XL Logic. It reads the local brightness level and exposes the same number both to comparators and to Python.

Sensor endpoint Comparator output Complete
Back to block overview
In game

What the sensor reports.

  • Right click prints the endpoint name and the sampled light level.
  • The comparator output is the same light level clamped to 0 through 15.
  • Name tags can rename the endpoint for Python lookup.
Python commands

Minimal and direct.

  • light_level(): returns the current local raw brightness from 0 to 15.
  • state(): common endpoint metadata plus the current light level.
  • rename(name), available(), summary(), and describe().
