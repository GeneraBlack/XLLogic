Block reference

Clock

The clock block exposes both Minecraft time and wall-clock time. It is useful for schedules, day-phase displays, and scripts that should react to a specific world-time window.

In game

Time readout and analog output.

  • Right click prints endpoint name, in-game day time, real-world time, and a combined mode hint.
  • The comparator output maps the 24000-tick Minecraft day onto 16 analog steps.
  • Name tags can rename the endpoint for scripting.
Python commands

Time methods

  • game_time(): absolute server game time.
  • day_time(): current day-phase tick inside the 24000-tick cycle.
  • real_time(): formatted real-world timestamp string.
  • state(): common endpoint metadata plus the time fields.
  • rename(name), available(), summary(), and describe().
