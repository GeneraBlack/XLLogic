Block reference

Redstone Bus Cable

Redstone bus cable transports all 16 logical channels through one visible network. It is a topology block, not a Python endpoint, and its main interface is the in-game bus debugger.

16-channel transport No direct Python device Complete
Back to block overview
In game

Bus debugger behavior.

  • Right click prints the bus summary and one summary line for every active channel flow.
  • Shift-right-click expands the view with route hops, blockers, and attached Redstone I/O device summaries.
  • Topology changes notify neighboring bus networks so channel state stays synchronized.
  • The block connects to other bus cables, coloured bus filters, and bus-aware Redstone I/O devices.
Python note

Scripts see the bus through Redstone I/O.

  • The cable itself has no endpoint name and no direct device handle.
  • Channel assignment and channel readings are exposed through Redstone I/O methods such as channel(side) and channels().
