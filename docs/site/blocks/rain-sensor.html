Rain Sensor

The rain sensor is the weather trigger block of XL Logic. It detects whether rain currently reaches the sensor position and exposes a simple boolean and analog view of that state.

Weather endpoint Comparator output Complete
Back to block overview
In game

Weather signal behavior.

  • Right click prints endpoint name and whether the block currently reads rain.
  • The comparator output is 15 when it is raining and the sensor can see the sky; otherwise it is 0.
  • Name tags can rename the endpoint for scripts.
Python commands

Weather methods

  • is_raining(): boolean rain check at the sensor position.
  • rain_level(): 15 when raining, otherwise 0.
  • state(): common endpoint metadata plus rain fields.
  • rename(name), available(), summary(), and describe().
